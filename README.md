# Linux Infra Lab

A practical Linux infrastructure and systems engineering laboratory focused on:

- Linux systems administration
- shell tooling and automation
- infrastructure experimentation
- observability and monitoring
- Docker and containerized environments
- operational Python tooling
- networking fundamentals
- systems diagnostics and troubleshooting

This repository serves as a hands-on engineering environment for studying, documenting, and building real-world infrastructure and automation workflows.

In addition to infrastructure experiments and operational tooling, the repository also contains structured technical notes and practical documentation covering Linux fundamentals, networking, monitoring, services, permissions, and troubleshooting workflows.
